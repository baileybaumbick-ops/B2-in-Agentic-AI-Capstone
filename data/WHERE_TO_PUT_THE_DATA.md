# Put the course dataset here

This repository does not redistribute the course dataset or the instructor's materials.

1. Download the course ZIP ("Final Assignment - Spotify Reviews Dataset.zip") from the course link and unzip it into this `data/` folder.
2. Expected files: `spotify_reviews_18months.csv` (97,400,616 bytes, SHA-256 `1fc85de68a304dd8978b537cfa58793d5f41cbaf417fa32cb53899f83a2fcef6`), `cost_100.csv` (SHA-256 `c884ac3b9be5066995d5063f96ad9af6e5e082975788c1684c4f6b6ea661dd0e`), `checkpoint_500.csv`, `analysis_10000.csv`, `golden_50_to_label.csv`, `manifest.json`, and `check_submission.py`.
3. The pipeline finds `check_submission.py` in `data/` automatically.

Source data: BwandoWando, "3.4 Million Spotify Google Store Reviews", version 2, Kaggle (publisher-listed license CC0: Public Domain).
